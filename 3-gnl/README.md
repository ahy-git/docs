O objetivo do get_next_line é retornar uma linha por chamada a partir de um file descriptor. Como o read pode ler mais bytes do que uma única linha, eu uso uma variável estática para guardar o conteúdo excedente entre chamadas. A função lê em blocos de BUFFER_SIZE, junta esse conteúdo em um buffer persistente, extrai a linha até o \n ou até o fim da string, atualiza o restante e retorna a linha alocada. No bônus, eu mantenho um rest separado para cada file descriptor.
